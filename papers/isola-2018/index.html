ISoLA 2018

Mar 27, 2018 Dominic Steinhöfel
This page supplies additional material for the reviewers of the paper “*Automatically Proving the Correctness of Compilation Rules*“, submitted to [ISoLA 2018](http://www.isola-conference.org/).

The extended technical report based on the ISoLA paper can be found here. The technical report additionally contains material that we had to leave out in the submission for space reasons. For convenience, we also created a PDF file visualizing the difference between the technical report and the submission (parts highlighted in blue are only contained in the technical report, while parts highlighted in yellow are only contained in the submission).
