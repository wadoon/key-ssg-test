TimSort (Tools and Proofs of JAR submission)

Jan 9, 2017 Richard Bubel
The file TimSortProofs.zip contains the KeY Tool, the TimSort source file as well as the saved proofs of the TimSort case study. After unzipping you find the following directory structure **bin/**This directory contains the used version of the KeY Tool. You can start KeY with the command `java -XmxG -jar KeY.jar`(assuming you are in the directory `bin` otherwise you need to specify the full path to the file `KeY.jar`). Attention: You need Java 8 to run KeY.
